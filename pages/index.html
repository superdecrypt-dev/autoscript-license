Autoscript IP License

Portal ini dipakai untuk mengaktifkan atau memperpanjang izin IP VPS autoscript. Setiap aktivasi sukses akan menambah masa aktif 14 hari untuk IP yang sama.

Alur Singkat

  1. Masukkan public IPv4 VPS Anda pada form aktivasi.
  2. Portal akan membuat atau memperpanjang izin IP tersebut.
  3. Gunakan form status untuk memastikan masa aktif terbaru.
Catatan

Jika IP VPS berubah, lakukan aktivasi ulang dengan IP baru. Jika status menunjukkan revoked, IP harus dibuka lagi oleh operator.
